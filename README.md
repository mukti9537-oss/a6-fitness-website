Project-Name : Workout Planning

Workout Planning is a modern and responsive fitness planning web application that helps users explore workout exercises, view detailed workout information, and create their own personalized workout plans.

Technologies Used: 1) Next.js
                   2) React
                   3) TypeScript
                   4) Tailwind CSS
                   5) React Icons
                   6) React Toastify
                   7) Context API
                   8) REST API
Features:
1)Workout Explore : Users can browse different workout exercises and find suitable workouts.

2)Workout Details : Users can click on a workout and view its complete details on a dedicated details page.

3)Create Workout Plan : Users can add workouts to their personal workout plan.

4)My Plan : Users can view all the workouts they have added to their plan.

5)Saved Workouts : Users can save their favorite workouts for later.

6)Dynamic Plan Counter : The navbar automatically displays the number of workouts currently added to the plan.

7)Responsive Design : The website is fully responsive and works smoothly on desktop, tablet, and mobile devices.

8)Toast Notifications : Users receive notifications when adding, removing, or saving workouts.
